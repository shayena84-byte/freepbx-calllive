# Проверка комплекта CallLive 15.0.9

Проверка от 9 ноября 2026 года выполнена на стенде с FreePBX 15.0.38, Core 15.0.22.39, Asterisk 16.2.1, PHP 7.4 и MariaDB. Использован архив, указанный в [контрольных суммах](../dist/15.0.9/SHA256SUMS.txt).

| Сценарий | Результат |
| --- | --- |
| Подписанный модуль 15.0.8 → 15.0.9 | Module Admin установил архив. FreePBX принял подпись 15.0.9, созданную прежним локальным ключом. Страница, CSS и JS загружаются. |
| Сборщик 15.0.8 при обновлении интерфейса | Сборщик совместим с модулем 15.0.9. PID службы и хеши файлов сборщика совпали до и после обновления. |
| История и доступ | Прежняя карточка реального тестового SIP-вызова с RTP/RTCP открылась в новой версии. Файл записи совпал побайтно. Доступ с разрешением `calllive` проверен. |
| Переход со старого сборщика | Проверены `--check-only`, автоматический откат после имитации ошибки перезапуска и установка совместимого сборщика 15.0.8. Прежняя запись истории осталась читаемой. |
| Целостность | Изменение CSS обнаружено проверкой FreePBX и заблокировано скриптом подписи. Подпись снова действительна после восстановления файла из архива. |
| Интерфейс и сборщик | Пройдены сценарии отображения маршрута, выбора канала, отметки на графиках и работы без замеров, а также 17 тестов Python. |

Операции systemd выполнялись через тестовую обвязку. AMI, SIP/RTP, Module Admin и проверка подписи FreePBX использованы на стенде. Код сборщика разобран грамматикой Python 3.6, а запуск тестов выполнен на Python 3.12. Проверку оформления в браузере вашей рабочей АТС выполните после установки.
