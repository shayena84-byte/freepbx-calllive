# Проверка CallLive 15.0.8

Дата: 8 ноября 2026 года. Проверки выполнены в изолированной лаборатории. Производственная АТС пользователя не изменялась.

## Среда и результат

FreePBX **15.0.38**, Core **15.0.22.39**, Asterisk **16.2.1**, MariaDB, PHP **7.4**. Использовались настоящие SIP/PJSIP-каналы и поток RTP/RTCP от тестовых телефонов. Python выполнения — **3.12**. Исходники дополнительно разобраны грамматикой Python 3.6; выбор пути `python3.6` проверен отдельной фикстурой. Это не запуск дистрибутива CentOS 7 или самого интерпретатора Python 3.6.

| --- | --- |
| Загрузка архива в Module Admin и обновление 15.0.7 → 15.0.8 | Установлено штатным интерфейсом, модуль включён, страница/JS/CSS возвращают HTTP 200 |

В репозитории есть **17 модульных тестов Python**: группировка мостов/каналов, AMI, атомарные снимки и новый журнал. Они успешно выполнены. Отдельный DOM-стенд проверил сценарии интерфейса с данными реального SIP-вызова; это проверка поведения кода, а не визуальная проверка в нескольких браузерах.

## Пределы проверки

Сценарий обновления проверен с настоящим локальным AMI, но операции systemd/установки изолированы фикстурой и временными путями. На производственной АТС команда дополнительно проверит реальный перезапуск и свежий снимок; при ошибке попытается восстановить прежние файлы и покажет фактический результат.

События очередей и переводов проверены на синтетических AMI-последовательностях, включая TransfererUniqueid/OrigTransfererUniqueid и назначение перевода. Полный реальный маршрут очереди/консультационного перевода, конференции и аппаратные DAHDI/IAX на этом стенде не прогонялись. Набор событий зависит от Asterisk и конфигурации AMI.

Сборка тестовой криптографической подписи использовала Sequoia, поскольку среда тестирования блокирует Unix-сокет gpg-agent. Проверка готовых подписей выполнялась настоящим GPG и штатным API FreePBX. Публикуемый CLI-скрипт использует установленный на АТС GPG; серверные ключи и реквизиты в релиз не включены.

## Повторение доступных тестов

Из корня репозитория:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 -m unittest discover -s tests -v
node --check calllive/assets/js/calllive.js
php -l calllive/Calllive.class.php
php -l calllive/page.calllive.php
bash -n calllive/deploy/update-root.sh
(cd calllive && sha256sum -c deploy/files.sha256)
```

Перед эксплуатацией на своей АТС выполните тестовый внутренний и внешний вызовы, проверьте сохранённую карточку и сравните оба номера версии в диагностике. История и статистика накапливаются с момента запуска нового сборщика.
